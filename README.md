# Face Recognition Attendance System

## Overview
This is a Face Recognition Attendance System developed using Python, SQL, and OpenCV. The system automatically recognizes faces and marks attendance.

## Features
- User Login and Registration
- Face Detection
- Face Recognition
- Automatic Attendance
- SQL Database Integration

## Technologies Used
- Python
- OpenCV
- SQL
- Tkinter (if used)

## Project Structure
- login.py
- register.py
- attendance.py
- database.sql
- images/
